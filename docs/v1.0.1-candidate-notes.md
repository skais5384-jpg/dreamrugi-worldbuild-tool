# 1.0.1 후보 변경 사항

## 현행 — 보관 복원·선택 회수 직접 확인 후 후보 / 2026-10-04

V1-ARCHIVE-RECOVERY-FIX-001의 보관 정의 복원·보관 입력 선택 회수를 구현하고, 사용자가 다시 허용한 Computer Use로 합성 프로젝트의 실제 동작을 확인했다. 같은 ID 복원 뒤 읽기 중복·거짓 경고, 저장 뒤 오래된 복원 안내, 보관 문서 이름, 생성 실패 안내 중복, 비교 항목의 이름·유형 표시와 실제 비교 동작에 맞지 않는 안내를 수정했다. 기존 디자인 정책에 따라 보관 목록과 보조 이력, 현재/보관 값, 선택 수, 빨간 제한 이유, 독립 스크롤과 고정 하단 명령을 정리했다.

프런트엔드 531 PASS/10 skip, 관련 네이티브 15 PASS/2 ignored와 별도 검토를 완료했다. 최종 개발 실행판 1.0.1에서 영향 흐름과 정상 저장·종료·재열기를 확인했으며, 서명 설치판 검증과 구분한다. 시험 자료 M11의 미지원 하위 타입은 실패를 보존하고 지원 타입으로 고쳤다. OBS-001 과거 그룹 보관 관측의 원인은 여전히 미확정이다.

사용자 본인의 최종 수용과 배포 재개 지시는 아직 없다. 공개판은 1.0.0이며 **1.0.1 정식 Release/latest·stable feed는 보류**한다. 기존 첫 draft와 운영 피드를 유지한다. 소스 반영은 배포 완료가 아니다. 최신 실행 후보·확인 가이드·채널별 검증 상태는 [현행 보고](https://github.com/skais5384-jpg/worldbuild-tool/issues/1#issuecomment-5969431956)를 따른다. 아래 CU 보류와 이전 실행 상태는 당시 이력이다.

## 이전 — 최초 후보 안내

상태: V1-ARCHIVE-RECOVERY-FIX-001 기술 검증·별도 검토 후 사용자 수동 확인을 위한 후보 준비. 공개판은 1.0.0이며 정식 1.0.1·latest·운영 피드는 보류한다.

- 저장 뒤 리소스 재점검은 마지막 문서·템플릿 편집이 끝난 뒤 자동 완료한다.
- 문서 트리는 자식과 손자를 오른쪽에 표시하고 같은 깊이의 이름을 정렬한다.
- 반복 카드의 자동 번호 제목은 생략하며 지정한 서식 텍스트 제목을 한 번 표시한다.
- 템플릿의 보관된 정의에서 필드·그룹·하위 필드·선택지를 원 ID로 복원한다. 저장 전 보관 취소는 다른 입력을 유지한다.
- 원본이 달라진 새 문서·기존 문서·템플릿 입력을 현재 값과 비교한다. 기본은 현재 유지이며, 선택한 보관 입력을 정상 편집·저장으로 회수한다.
- 복합 입력은 필요한 템플릿 변경을 먼저 회수·저장한 뒤 같은 원 보관본의 문서 입력을 최신 기준으로 다시 비교한다. 일부 적용을 전체 완료로 표시하지 않는다.

원 보관본과 첨부는 비교·취소·편집 진입·부분 적용으로 삭제하지 않는다. 정의가 실제로 없거나 현재 문서의 정의 기록이 손상된 경우 제한 이유를 표시하며 보관 본문을 읽고 복사할 수 있다. 본문 복사는 원 보관 파일·첨부 전체를 내보내는 기능이 아니다. 결과 불명 저장은 새 회수로 우회하지 않는다.

카드 제목 선택 뒤 그룹이 예상 밖으로 보관된 과거 관측의 원인은 미확정이다. 원 표본을 보존하며 새 후보의 제목 선택·화면 이동·저장·재열기는 사용자 확인 항목으로 남긴다.
