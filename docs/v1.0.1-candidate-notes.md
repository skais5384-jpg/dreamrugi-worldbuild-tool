## 현행 — 문서 중심 초안과 버전 기록 / 2026-10-04

V1-DATA-SAFETY-UX-002의 구현과 직접 검증을 진행 중입니다. 공개판은 아직 1.0.0입니다. 아래 정책이 기존 복구 센터와 무제한 보관 세대 안내를 대체합니다. 모든 필수 검사와 실제 서명 설치판 검증을 마친 뒤 같은 후보를 1.0.1로 공개합니다. 개발 실행판이나 일부 검사 성공을 배포 완료로 표시하지 않습니다.

- 문서·템플릿을 먼저 생성하고 이어서 편집합니다. 빈 필수 항목은 저장을 막지 않으며, 편집을 나갈 때 한 번 안내합니다.
- 문서·템플릿마다 최신 미저장 입력 하나를 보존합니다. 해당 항목을 편집하면 원본과 충돌하지 않는 입력은 바로 이어집니다. 실제 충돌만 현재 내용과 비교합니다. 별도의 공용 초안·고아 목록과 복구 센터는 제공하지 않습니다.
- 편집 종료 때 내용이 바뀌었으면 확정 버전 하나를 기록합니다. 생성 기준본을 포함해 최근 열 개를 남기며 번호는 계속 증가합니다. 자동 저장, 무변경 종료, 수정 후 원상 복귀에는 중복 버전을 만들지 않습니다.
- 버전 기록에서 정상 읽기 화면으로 미리보고 같은 항목에 복원합니다. 복원은 새 확정 버전이며 현재 내용을 뒤로 덮는 취소 작업이 아닙니다. 템플릿 복원은 현재 템플릿 수정처럼 문서에 반영하고 문서 본문은 보존합니다.
- 버전 이력만 참조하는 첨부를 위해 파일을 복사하거나 삭제를 막지 않습니다. 과거 첨부가 없으면 누락 위치를 안내하고 나머지 내용을 복원·수정·저장할 수 있습니다. 잘못된 새 참조나 프로젝트 밖 파일 연결까지 허용하지 않습니다.
- 현재 파일이 누락되거나 손상되어도 정상 목록의 해당 항목에서 유효한 버전을 확인합니다. 모든 버전을 읽을 수 없으면 범위를 설명하고 프로젝트 백업 복원을 안내합니다.
- 휴지통 이동·복원·영구 삭제에는 그 항목의 초안과 버전 기록이 함께 따릅니다. 독립 프로젝트 백업은 별도입니다.
- 기존 누적 초안과 형식 이력은 내용을 검증한 전환 백업을 먼저 만든 뒤 이관합니다. 중단된 전환은 같은 대상에 안전하게 재개하며 미확인 자료를 지우지 않습니다. 문서를 해석하는 데 필요한 보관 정의와 값은 유지합니다.
- 이전 앱이 새 저장 규칙을 우회하지 않도록 프로젝트를 처음 읽거나 편집하기 전에 저장 형식을 전환합니다. 전체 자료를 독립 백업으로 검증한 뒤 내용·첨부 참조·편집 횟수는 그대로 유지합니다. 전환 후에는 1.0.0에서 이 프로젝트를 편집하지 마세요. 이전 앱으로 돌아가려면 전환 전 전체 백업을 별도 프로젝트로 복원해야 합니다. 실제 1.0.0 설치판 업그레이드 시험은 아직 완료하지 않았습니다.
- 프로젝트 백업에는 저장 내용, 버전 기록, 실제 존재하는 첨부와 보존된 최신 입력이 들어갑니다. 아직 보존되지 않은 입력과 없던 첨부는 들어가지 않습니다. 진행 중 안전 백업은 보호하고 완료된 자동 안전 백업은 최근 한 개를 남깁니다. 수동 백업은 유지합니다.
- 일반 화면에는 내부 식별자·해시·원시 JSON·진단 코드를 표시하지 않습니다. 필요한 진단은 실행 기록에서 확인합니다. 기존 보관 정의의 같은 항목 복원, 카드 제목, 트리 정렬, 마지막 편집 종료 뒤 자동 점검을 유지합니다.

사용자 수동 확인은 이번 요청에서 제외됐으며 실행자가 Computer Use로 직접 확인합니다. 공식 도구와 실제 인증·키·GitHub required reviewer 통제를 지킵니다. Store·블로그·다이어그램은 이번 배포에 포함하지 않습니다. 아래 이전 후보의 시험 수치를 이번 수정 후보의 결과로 재사용하지 않습니다.
