# Dreamrugi Worldbuild Tool 1.0.1

- 문서를 저장하고 편집을 마치면 리소스 상태를 자동으로 다시 점검합니다. 진행 중인 점검과 실제 점검 실패를 구분합니다.
- 문서 트리에서 같은 깊이의 이름을 정렬하고 하위 문서를 더 오른쪽에 표시합니다.
- 반복 카드 읽기의 자동 항목 번호를 숨깁니다. Template에서 카드 제목 필드를 지정하면 그 값만 제목으로 한 번 표시합니다. 기존 자료는 자동 변경하지 않습니다.
- 현재 Template에서 찾을 수 없거나 보관된 필드는 빨간 느낌표와 경고 문구로 표시합니다. 저장된 값은 계속 읽을 수 있습니다.

GitHub 1.0.0은 앱 시작의 업데이트 확인 뒤 업데이트 후 재시작으로 전환합니다. 프로젝트와 보관 입력을 보존하고 다시 열어 확인해 주세요. 0.1.0은 수동 설치가 필요합니다. 한국어 UI·Windows x64·현재 사용자 범위 설치·WebView2 요구 사항은 같습니다. Store 배포는 별도입니다. 검색/큰 백업 성능 잔여 및 과거 새 문서 첫 읽기 경고 추적은 별도로 유지합니다.
