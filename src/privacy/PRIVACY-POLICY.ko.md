## 1. 적용 범위와 기본 구조

Dreamrugi Worldbuild Tool은 Windows에서 문서와 세계관 자료를 작성·관리하는 데스크톱 앱입니다. 이 방침은 앱의 개인정보 처리와 운영자가 받는 지원·개인정보 문의에 적용됩니다. 정책을 게시하는 블로그 자체의 방문 기록이나 계정 처리는 해당 블로그 서비스의 방침에 따릅니다.

문서와 첨부파일은 기본적으로 사용자의 기기에 저장됩니다. 앱은 자체 회원가입을 요구하지 않으며, 프로젝트를 Dreamrugi의 서버로 자동 업로드하는 기능이나 앱 자체의 광고·이용 분석·운영자 대상 자동 오류 전송 기능을 두고 있지 않습니다. 외부 콘텐츠, 업데이트, Windows·WebView2 기반 서비스, 사용자가 설정한 협업 서버에서는 별도의 통신이 발생할 수 있습니다.

로컬에서 처리하는 문서나 파일에도 개인정보가 포함될 수 있습니다. 따라서 “개인정보를 전혀 처리하지 않는다”거나 “항상 외부 통신 없이 작동한다”는 의미는 아닙니다.

진단 기록에는 시간, 처리 단계, 오류 분류, 결과, 작업 식별자, 프로젝트 지문 등이 포함될 수 있습니다. 복구·저장 중단 관련 자료에는 원래 입력이나 경로가 포함될 수 있으므로, 진단 기록의 제한된 항목이 모든 보관 파일에 똑같이 적용되는 것은 아닙니다.

PDF 출력은 저장된 문서와 로컬 이미지·글꼴로 처리하며 외부 영상이나 YouTube 플레이어를 불러오지 않습니다. 출력용 WebView2의 기반 서비스 처리는 3절과 같습니다. 첨부파일을 연 외부 프로그램의 추가 처리에는 그 프로그램의 방침이 적용됩니다.

사용자가 프로젝트나 백업을 클라우드 동기화·공유 폴더에 저장하면 해당 서비스가 자료를 동기화할 수 있습니다. 사용자가 선택한 서비스의 설정과 방침도 확인해 주세요.

## 3. 외부 연결이 발생하는 경우

| 기능 | 외부에서 받을 수 있는 정보 | 연결 시점과 대상 |
| --- | --- | --- |
| GitHub 배포판의 업데이트 확인 | IP 주소, 요청 시각·주소, 업데이트 도구의 브라우저 식별 문자열(User-Agent) 등 연결 정보 | 앱 시작 시 자동으로 업데이트를 확인하며 실패 시 재시도가 발생할 수 있습니다. GitHub의 배포 정보 서버에 연결합니다. |
| GitHub 배포판의 업데이트 다운로드 | 위 연결 정보와 요청한 설치 파일 정보 | 사용자가 업데이트를 선택하면 GitHub의 다운로드 서버에 연결합니다. 업데이트 요청에 프로젝트 본문이나 SVN 암호를 넣지 않습니다. |
| Microsoft Store 배포판의 설치·업데이트 | Microsoft가 처리하는 계정·기기·설치·업데이트 관련 정보 | Microsoft Store가 처리합니다. 이 배포판에서는 앱의 GitHub 업데이트 기능을 사용하지 않습니다. |
| Windows·WebView2 기반 서비스 | 보안 확인에 필요한 접속 정보, 필수 또는 선택 진단·충돌 관련 정보 등 | Microsoft의 서비스와 기기·계정·진단 설정에 따라 발생할 수 있습니다. Dreamrugi의 자동 오류 수집과는 별개입니다. |
| 외부 이미지·영상과 YouTube | 요청한 주소나 영상 식별자, IP 주소, 요청 시각, 브라우저·기기 정보, 서비스가 사용하는 쿠키·저장 정보 등 | 문서나 편집 미리보기에 표시될 때 입력한 콘텐츠 서버 또는 Google·YouTube에 연결할 수 있습니다. 아래 4절을 확인해 주세요. |
| 외부 사이트·이메일 링크 | 해당 사이트나 이메일 서비스에서 처리하는 접속·메시지 정보 | 사용자가 외부 열기를 선택하면 기본 브라우저나 이메일 프로그램으로 전달합니다. |
| SVN 협업 | 서버 주소, 인증 계정·암호, 저장소 경로, 잠금 정보, 파일·문서 본문, 커밋 메시지 등 작업에 필요한 정보 | 사용자가 지정한 서버에 연결합니다. 연결 설정 후 상태·잠금 확인 등이 자동으로 발생할 수 있으며, 커밋은 사용자의 작업에 따라 수행합니다. 로컬 저장소를 사용할 때는 원격 서버 전송과 다릅니다. |

GitHub 업데이트 화면에서 ‘나중에’를 선택해도 향후 앱 실행 때의 자동 업데이트 확인이 영구적으로 중단되는 것은 아닙니다.

업데이트 정보는 raw.githubusercontent.com에서, 필요한 배포 확인 정보는 api.github.com에서 요청합니다. 조회 실패 뒤 사용자가 ‘다시 시도’를 선택하면 다시 접속합니다. 설치 파일은 사용자가 업데이트를 선택한 뒤 받습니다.

두 배포판은 WebView2의 기본 Microsoft Defender SmartScreen과 진단 동작을 별도로 끄지 않습니다. SmartScreen 보안 확인에 필요한 정보가 Microsoft로 전송될 수 있습니다. WebView2는 필수 진단을 처리하고, Windows 설정에 따라 선택 진단을 처리하며, 충돌 시 진단 파일을 Microsoft에 보낼 수 있습니다. 선택 진단은 Windows 진단 설정에서 관리합니다. Dreamrugi가 이 자료를 직접 받는 것은 아닙니다.

외부 서비스에 전송된 접속 기록, 협업 이력 등의 보관 기간은 해당 서비스의 정책이나 서버 운영 기준에 따릅니다. 앱에서 링크·설정·자료를 삭제해도 외부 서비스의 기존 기록까지 자동으로 삭제하지는 않습니다. 서버 운영 위치와 서비스 구성에 따라 해외 처리가 발생할 수 있으며, 특정 URL만으로 처리 국가나 법적 관계를 확정할 수는 없습니다.

## 4. 외부 이미지·영상과 YouTube

로컬 첨부파일과 외부 URL 콘텐츠는 처리 방식이 다릅니다. 외부 URL을 사용하는 이미지는 표시할 때 해당 서버에서 받아오며, 일반 영상은 재생을 누르기 전에도 길이 등 기초 정보를 읽기 위해 접속할 수 있습니다. YouTube 플레이어는 아래의 방침 수락과 자동 불러오기 허용 후 화면에 표시될 때부터 연결할 수 있습니다. 따라서 외부 열기나 재생 버튼을 누르지 않았더라도 통신이 발생할 수 있습니다.

YouTube는 처음에 차단되어 URL 링크만 표시됩니다. 링크를 누르면 외부 브라우저로 열며, 이 동작은 앱 내 불러오기 동의가 아닙니다. 도움말의 개인정보·YouTube 설정에서 방침 수락과 YouTube 플레이어·썸네일 자동 불러오기 허용을 각각 선택할 수 있습니다. 허용하면 표시 중인 영상의 플레이어와 썸네일이 자동으로 표시되며 재생은 직접 눌러 시작합니다. 선택은 같은 기기의 앱 사용자 환경에 기억하며 영상·프로젝트마다 다시 받지 않습니다. 허용 철회도 같은 설정에서 할 수 있습니다. 철회하면 열린 플레이어를 해제하고 이후 앱 내 YouTube를 불러오지 않으며 URL 링크로 돌아갑니다. 이미 보낸 외부 기록까지 삭제되지는 않습니다.

일반 이미지는 자동 표시하며 일반 영상은 재생 전 정보 조회가 가능하므로 위 YouTube 선택과 구분됩니다. 다른 사람이 작성한 프로젝트의 외부 URL도 같은 처리 방식이 적용됩니다.

이미지 요청에서는 참조 페이지 주소 전송을 제한합니다. YouTube에는 고정된 앱 출처 식별자를 사용합니다. 이러한 조치가 IP 주소를 숨기거나 모든 쿠키·추적·외부 통신을 막는 것은 아닙니다. YouTube는 개인정보 보호 강화 모드의 임베드 주소를 사용합니다. 이 모드도 Google·YouTube 접속이나 모든 쿠키·광고·저장 처리를 없애는 기능은 아닙니다.

YouTube 콘텐츠를 이용하면 [YouTube 이용약관](https://www.youtube.com/t/terms)이 적용되며, Google의 정보 처리는 [Google 개인정보처리방침](https://policies.google.com/privacy)에 설명되어 있습니다. 외부 플레이어는 서비스 정책과 환경에 따라 광고를 표시하거나 쿠키와 유사한 저장 기술을 사용할 수 있습니다. 이는 앱 자체의 광고 SDK나 분석 기능과 구분됩니다.

민감한 내용이나 비공개 접근 토큰이 들어 있는 URL은 외부 콘텐츠 주소로 사용하지 않는 것이 좋습니다. 외부 사이트의 로그인 상태·쿠키·기기 저장소를 관리하는 방법과 관련 권리 요청은 해당 서비스의 안내도 확인해 주세요.

## 5. 지원 및 개인정보 문의

이메일로 문의하면 발신 주소, 표시 이름, 문의 본문, 사용자가 직접 첨부한 파일을 받습니다. 문의 응답, 요청한 문제 해결, 개인정보 권리 요청 처리에 필요한 범위에서 이용하며 광고나 홍보 목적으로 사용하지 않습니다. 앱이 진단 자료나 프로젝트를 문의 주소로 자동 전송하지는 않습니다.

운영자는 NAVER 메일을 이용합니다. 메일 전송·보관에는 발신자가 사용하는 메일 서비스와 NAVER 등 송수신 서비스도 관여합니다. 운영자의 문의 처리 책임과 각 메일 서비스의 자체 처리는 구분됩니다.

문의 자료는 해결에 필요한 동안 보관하고, **해결 완료 후 90일이 지나면 삭제합니다.** 목적에 더 이상 필요하지 않은 정보는 그 전이라도 정리하며, 특히 불필요한 민감 첨부자료를 계속 보관하지 않습니다. 미해결 문의도 실제로 처리가 필요한지 점검하여 불필요하게 장기 보관하지 않습니다.
